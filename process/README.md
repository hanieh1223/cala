# مدل فرایند

`purchase-request-reference.bpmn` یک مدل مرجع BPMN 2.0 برای مرور منطق جریان است.

این فایل:
- یک PMX نیست.
- دارای Dynaform بومی ProcessMaker نیست.
- به‌عنوان فرایند اجرایی ProcessMaker تست نشده است.
- برای نمایش/بازبینی ساختار جریان طراحی شده است.

برای خروجی قابل Import، فرایند باید در ProcessMaker 3.5.8 Designer ساخته و از قابلیت Export Process همان نسخه صادر شود. فایل PMX حاصل پس از تست Import در محیط مجزا باید در همین پوشه قرار گیرد.
