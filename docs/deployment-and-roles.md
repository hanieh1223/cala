# راهنمای استقرار، Import و نقش‌ها

## پیش‌نیاز

- ProcessMaker Community Edition نسخه 3.5.8 در محیط آزمایشی.
- دسترسی Designer و مدیریت PM Tables.
- دسترسی محدود و کنترل‌شده برای ایجاد سه جدول.
- پشتیبان‌گیری از workspace و دیتابیس پیش از تغییر.

## جدول‌ها

فایل `tables/purchase-tables.sql` را در دیتابیس انتخاب‌شده اجرا کنید. این جداول سفارشی هستند و جایگزین APP_* یا جدول‌های داخلی ProcessMaker نیستند. دسترسی حساب دیتابیس باید حداقلی باشد. در محیط چند workspace، نام‌گذاری/جداسازی داده‌ها را مطابق معماری نصب انجام دهید.

PM Tables و Report Tables از طریق مسیر Export/Import مخصوص خود منتقل می‌شوند و جزو PMX فرایند نیستند. اسکریپت SQL این مخزن، جدول‌های سفارشی MySQL ایجاد می‌کند و Export بومی PM Table محسوب نمی‌شود.

## ساخت فرایند

1. در Designer یک Process با نام «مدیریت درخواست خرید» ایجاد کنید.
2. عناصر BPMN را مطابق `process/purchase-request-reference.bpmn` و `process-design.md` بسازید.
3. متغیرهای فرایند را مطابق جدول مستندات تعریف کنید.
4. سه Dynaform را با مشخصات `forms-and-validation.md` ایجاد کنید.
5. کدهای Trigger مرجع را بررسی و در ProcessMaker به Triggerهای متناظر تبدیل کنید.
6. هر Trigger را در نقطه اجرای درست متصل کنید؛ به‌ویژه محاسبه باید پیش از Gateway اجرا شود.
7. گروه درخواست‌کنندگان را به User Task ثبت درخواست و گروه مالی را به User Task پرداخت تخصیص دهید.
8. دسترسی فرم نتیجه و متغیرهای سیستمی را فقط خواندنی نگه دارید.
9. پس از تست، از Designer گزینه Export Process را انتخاب و فایل PMX را تولید کنید.
10. PMX را در workspace آزمایشی جداگانه Import و اشیای فرایند را بازبینی کنید.

## نقش‌ها و تخصیص

- درخواست‌کننده: شروع Case و ثبت فرم درخواست.
- کارشناس مالی: تکمیل فرم پرداخت برای درخواست‌های تأییدشده.
- مدیر فرایند/ادمین: نگهداری فرایند و دسترسی‌های طراحی؛ حق تغییر نتیجه بررسی از طریق فرم عادی ندارد.

در صورت الزام کسب‌وکار به پرداخت توسط همان درخواست‌کننده، تخصیص User Task پرداخت را متناسب با سیاست دسترسی تغییر دهید. کاربران و اعضای گروه‌ها به‌طور کامل داخل PMX منتقل نمی‌شوند و باید در مقصد تنظیم شوند.

## Export/Import

PMX باید توسط ProcessMaker تولید شود. فایل BPMN مرجع این مخزن را با PMX اشتباه نگیرید. پس از Export:
- اندازه فایل و وجود اشیای فرایند را بررسی کنید.
- در یک workspace آزمایشی Import کنید.
- Dynaformها، Triggerها، متغیرها و اتصال Gatewayها را بررسی کنید.
- گروه‌ها/کاربران و اتصالات خارجی را جداگانه تنظیم کنید.
- PM Tables و جداول سفارشی را مستقل منتقل کنید.

## محدودیت آزمون

در محیط تهیه این مخزن، ProcessMaker 3.5.8 نصب و در دسترس نبوده است. بنابراین Import، اجرای Case، ارسال فرم، اجرای Trigger یا آزمون رابط کاربری در ProcessMaker انجام نشده است.
